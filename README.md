# Teacher's Day Doraemon-Inspired Portfolio

An interactive Teacher's Day portfolio/letter created for Sir Randy Bello.

## Features

- Doraemon-inspired blue, yellow, and red design
- Responsive layout
- Smooth scrolling navigation
- Interactive envelope
- Smooth envelope flap opening
- Letter paper animation
- Teacher photo section
- Appreciation button animation
- Floating decorations
- Mobile-friendly design
- Reduced-motion accessibility support

## Project Files

- `index.html` — Main webpage
- `style.css` — Design and animations
- `script.js` — Interactions and functionality
- `sir-randy.jpg` — Place Sir Randy's photo here

## How to Use

1. Keep all files in the same folder.
2. Add Sir Randy's photo to the folder.
3. Name the photo `sir-randy.jpg`, or change the image filename in `index.html`.
4. Open `index.html` in a web browser.
5. Click **Open My Letter** and then **Open Letter**.

## Photo

The HTML expects:

```html
<img src="sir-randy.jpg" alt="Sir Randy Bello">
```

If your photo has another filename, update the `src` value.

## Customization

You can change the message directly inside `index.html`.

You can also change colors, spacing, animations, and other visual elements in `style.css`.

## Note

The visual style is Doraemon-inspired and uses original CSS shapes and themed colors rather than copying official character artwork.
